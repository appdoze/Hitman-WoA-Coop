# Spike reports

One file per spike from [Part 2 of the roadmap](../../WOA_COOP_ROADMAP.md#part-2-risk-spikes-do-these-first). Together they are the Month 3 milestone: the written test report that the [decision gate](../../WOA_COOP_ROADMAP.md#decision-gate-end-of-month-3) uses to pick a design tier.

To start one, copy [TEMPLATE.md](TEMPLATE.md) to the file name below and fill it in as you go. Update it when results change; don't start a new file.

When you create a spike's file, turn its file name in the table into a link and update the status.

Track day-to-day progress in each spike's issue (linked in the table). The roadmap holds the plan, the issue holds the ticks and discussion, and the file here holds the final write-up.

Rules from [CONTRIBUTING.md](../../CONTRIBUTING.md) apply: no decompiled game code, no game files, no personal data in logs or screenshots.
